# Синтез звуков (этап 6)

`synth.py` синтезирует все звуки игры в `assets/audio/` — без сторонних сэмплов и лицензий:

- `pick.ogg` — мягкий «тук», когда ребёнок берёт кусочек;
- `place.ogg` — двухнотный «дзинь», когда кусочек встал на место;
- `win.ogg` — радостное арпеджио и аккорд до мажор (~2,7 с);
- `music.ogg` — бесшовная петля 38,4 с: 16 тактов, 100 BPM, до мажор, I–V–vi–IV, колокольчики и мягкий бас.

Аддитивный синтез с мягкими огибающими, без резких верхов. Эффекты нормализованы к пику −3 dBFS, музыка — к RMS −20 dBFS. Звучание детерминировано (seed): при повторном запуске декодированные сэмплы совпадают, отличается только серийный номер Ogg-потока.

```bash
cd tools/audio
uv run synth.py
```

Скрипт печатает размер, длительность, пик, RMS, DC и скачок на стыке петли. Если libsndfile не умеет Vorbis, скрипт завершается с ошибкой (WAV не пишется — приложение грузит только `.ogg`): поставьте сборку libsndfile с поддержкой Vorbis.

Музыку можно заменить готовым файлом `assets/audio/music.ogg` без изменения кода.
